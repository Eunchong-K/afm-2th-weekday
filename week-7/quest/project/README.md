# Marked — 어디서 달려도, 기록은 이어진다.

해외에서도 러닝 루틴을 이어가고 싶은 러너를 위한 앱. 여행 중 달린 도시와 기록을 모으고, 나만의 스탬프 카드로 남겨요.

**지금 바로 사용하기**: https://project-sand-theta-93.vercel.app

---

## 이렇게 사용하세요

### 1. 회원가입 & 로그인

앱에 접속하면 로그인 화면이 나와요.  
이메일과 이름을 입력해 바로 가입할 수 있어요.

### 2. 러닝 기록 남기기

하단 메뉴에서 **기록** 탭을 누르면 기록 입력 화면이 열려요.

- **도시** — 달린 도시 이름을 입력하면 자동으로 국가도 채워져요
- **날짜** — 달린 날짜를 선택해요
- **거리 / 시간** — 킬로미터와 분 단위로 입력하면 페이스가 자동으로 계산돼요
- **메모** — 코스, 날씨, 기분 등 남기고 싶은 것을 자유롭게 적어요

입력 후 **저장하기** 를 누르면 기록만 저장되고,  
**스탬프 만들기 →** 를 누르면 바로 카드 만들기로 넘어가요.

> 이미 저장된 기록을 수정하려면 홈이나 히스토리에서 해당 기록을 탭하면 돼요.

### 3. 스탬프 카드 만들기

저장된 기록을 탭하면 스탬프 카드 편집 화면이 열려요.

- **템플릿 선택** — 지도형, 도시명, 라인, 로고, 여권도장 5가지 스타일 중 선택
- **배경 색상** — 아래 동그란 색상 버튼으로 배경을 바꿀 수 있어요
- **사진 추가** — 오른쪽 위 **사진** 버튼으로 내 사진을 배경으로 넣을 수 있어요
- **위치 조정** — 한 손가락으로 드래그하면 카드 내용이 움직여요
- **크기 조정** — 두 손가락을 벌리고 오므리면 카드 내용의 크기가 바뀌어요
- **언어** — KO / EN 버튼으로 한국어 / 영어를 전환해요

마음에 드는 카드가 완성됐으면 **저장하기 →** 를 눌러요.  
모바일에서는 사진 앨범에 바로 저장되고, PC에서는 파일로 다운로드돼요.

### 4. 내 달린 나라 보기

홈 화면에서 **내가 달린 나라** 지구본을 확인할 수 있어요.  
달린 나라가 색칠되어 한눈에 내 러닝 발자국을 볼 수 있어요.

### 5. 러닝 코스 탐색

하단 메뉴에서 **탐색** 탭을 열면 다른 러너들이 추천하는 전 세계 코스를 볼 수 있어요.

- **대륙 필터** — 아시아, 유럽, 아메리카 등 대륙별로 걸러서 볼 수 있어요
- **검색** — 도시명이나 코스 이름으로 검색할 수 있어요
- 코스를 탭하면 지도 링크와 해당 도시를 달린 다른 러너들의 기록도 확인할 수 있어요
- **코스 등록하기** 버튼으로 내가 달린 코스를 직접 추천할 수 있어요

---

## 주요 기능

| 기능 | 내용 |
|------|------|
| 러닝 기록 저장·수정 | 도시·거리·시간·메모, 페이스 자동 계산 |
| 스탬프 카드 제작 | 5가지 템플릿, 드래그·핀치로 자유롭게 편집 |
| 달린 나라 지구본 | 내가 달린 나라를 지구본으로 한눈에 확인 |
| 러닝 코스 탐색 | 대륙·도시별 코스 탐색 + 해당 도시 러너 기록 |
| 갤러리 저장 | 완성된 스탬프를 모바일 앨범에 바로 저장 |
