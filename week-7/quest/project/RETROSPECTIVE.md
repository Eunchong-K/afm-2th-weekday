# Marked — 프로젝트 회고

## 한 줄 소개

달린 곳마다 스탬프를 남기는 여행 러닝 기록 앱

---

## 회고

처음에는 여행과 다양한 액티비티를 함께 기록하는 앱을 구상했지만, 범위가 너무 넓어 구현이 어렵겠다고 판단해 **여행 + 러닝**으로 주제를 좁히고 핵심 기능을 세 가지로 압축했다. 러닝 기록 및 스탬프 카드 생성, 추천 러닝 코스 탐색, 달린 나라 지구본 컬러링이 그것이다. 기획 범위를 빠르게 줄인 덕분에 완성도 있는 프로토타입을 만들 수 있었던 건 잘 된 점이지만, 아쉬운 점도 남는다. GPS 기반의 정밀한 러닝 경로 기록과 코스 탐색을 구현하고 싶었으나 실제로는 국가 단위의 기록에 그쳤고, 국가별 타일 색상·스탬프 템플릿 등 디자인 요소를 더 다듬지 못한 것도 아쉽다. 앞으로는 건강 앱(애플 헬스, 가민 등)에서 러닝 데이터를 직접 불러오는 연동 기능을 추가하고 싶고, 러닝 외 다른 액티비티로도 확장할 수 있는 구조를 고려 중이다.

---

## 주요 기능 요약

| 기능 | 내용 |
|------|------|
| 러닝 기록 & 스탬프 | 도시·거리·시간 입력 → 5가지 템플릿으로 SNS 카드 제작 |
| 러닝 코스 탐색 | 대륙별 필터 + 도시 검색으로 전 세계 추천 코스 탐색 |
| 달린 나라 지구본 | 기록된 국가가 지구본에 색칠되어 한눈에 확인 |

---

## 잘 된 점

- 기획 범위를 초기에 빠르게 좁혀 완성도 있는 프로토타입 제작
- 스탬프 편집(드래그 위치 조정·핀치 크기 조정)이 모바일에서 자연스럽게 동작
- 모바일 갤러리에 바로 저장되는 Web Share API 연동

## 아쉬운 점

- 국가 단위 기록에 그침 — GPS 기반 정밀 경로 기록을 구현하지 못함
- 스탬프 템플릿·국가 타일 디자인을 더 다듬지 못함
- 건강 앱 데이터 연동(애플 헬스, 가민 등) 미구현

## 다음에 하고 싶은 것

- 운동 앱에서 러닝 기록 자동 가져오기
- GPS 경로 기록 및 지도 위 코스 시각화
- 러닝 외 다른 액티비티(하이킹, 사이클링 등) 지원
